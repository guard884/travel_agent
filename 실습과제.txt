실습 과제] LangGraph를 활용한 스마트 여행 비서 에이전트 구축
1. 과제 개요
본 과제는 LLM 오케스트레이션 프레임워크인 LangGraph를 활용하여, 사용자의 요구사항에 맞게 여행 
계획을 지원하는 '스마트 여행 비서 에이전트'의 핵심 워크플로우를 직접 설계하고 구현하는 것을 목표로 합니다.
제한 사항: 복잡한 구조의 이해를 돕기 위해, 고수준 API인 create_react_agent 사용은 금지합니다.
반드시 상태(State), 노드(Node), 에지(Edge)를 직접 정의하여 그래프를 구축해야 합니다.

2. 주요 요구사항 및 구현 기능
① 상태 관리 (State Definition)
에이전트 내부에서 대화 맥락, 사용자 입력, 툴 호출 결과, 중간 프로세스 데이터 등을 추적할 수 있는 
구조적인 State 객체를 정의합니다.

② 노드 및 에지 구현 (Nodes & Edges)
노드(Nodes): 사용자 입력 분석, 목적지 정보 RAG 검색, 외부 툴(날씨/환율) 
실행 등을 담당하는 개별 독립 함수를 구현합니다.

에지(Edges): LLM의 판단이나 조건에 따라 다음 노드로 제어 흐름을 넘겨주는 
조건부 에지(Conditional Edge)를 포함하여 워크플로우를 완성합니다.

③ 외부 툴 연동 (Tools Integration)
날씨 검색 Tool: 지정된 여행지의 날씨 정보를 가져오는 가상 또는 실제 API 연동

환율 계산 Tool: 여행 국가의 통화에 맞춘 환율 계산 기능

RAG 기반 문서 검색: 여행 가이드북이나 내부 데이터에서 목적지 추천 정보를 검색하는 RAG(Retrieval-Augmented Generation)
